# sms-policy

Public policy and opt-in pages for **SMS Assistant** — the A2P 10DLC text message
coordination program operated by Peter Nielson (sole proprietor).

Published with GitHub Pages at https://nielsonpa.github.io/sms-policy

| Page | Purpose |
| --- | --- |
| `/` | Program overview, operator identification, call to action |
| `/join` | Text-to-join call to action and end-to-end opt-in flow |
| `/privacy` | Privacy Policy (includes the required carrier disclosure language) |
| `/terms` | Terms & Conditions (program, frequency, rates, keywords, opt-out) |
| `/handout` | Printable handout distributed at in-person meetings |

Opt-in is by inbound SMS only. These pages must stay consistent with the strings
in the assistant's message templates and with the registered campaign fields.
